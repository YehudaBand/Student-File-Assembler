File Naming Convention & Sections

Required format: lastName_starsId_SECTION_fileName.ext
Example: Smith_12345_ISIR_transaction_2024.pdf

Every file must include the student's last name, their 5-digit STARS ID, and a valid section key. Files without a valid section key will be rejected.
